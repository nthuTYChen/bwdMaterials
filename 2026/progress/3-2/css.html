CSS Introduction

What CSS Is

CSS, or Cascading Style Sheets, is the language used to control the presentation of HTML documents. It defines how elements should appear in terms of layout, color, typography, spacing, and other visual properties.

CSS Rule Structure

A CSS rule consists of a selector and a declaration block. The selector targets HTML elements, while the declaration block contains property and value pairs, such as color: blue; or font-size: 16px;.

Selectors

CSS selectors are used to choose which HTML elements a rule applies to. Common selectors include element selectors, class selectors, ID selectors, and more advanced selectors such as attribute selectors and pseudo-classes.

The Cascade

The cascade is the process browsers use to decide which CSS rules apply when multiple rules target the same element. Specificity, source order, and inheritance all affect how final styles are determined.

Box Model

The CSS box model describes how elements are represented as rectangular boxes. Each box consists of content, padding, border, and margin, which together determine the size and spacing of elements on the page.

Responsive Design

CSS supports responsive design through features such as relative units, flexible layouts, and media queries. These tools help web pages adapt to different screen sizes and devices.
