HTML Introduction

What HTML Is

HTML, or HyperText Markup Language, is the standard markup language used to create the structure of web pages. It defines elements such as headings, paragraphs, links, images, tables, and forms.

Basic Document Structure

A typical HTML document begins with a <!DOCTYPE html> declaration, followed by the <html> root element. Inside it, the <head> contains metadata, while the <body> contains the visible page content.

Common HTML Elements

HTML includes many semantic and structural elements such as <header>, <main>, <article>, <section>, <footer>, <p>, and <a>. These elements help organize content clearly and meaningfully.

Attributes

HTML elements can include attributes that provide additional information. For example, the href attribute in an anchor element specifies the destination URL, and the src attribute in an image element specifies the image file path.

Semantic HTML

Semantic HTML uses elements according to their meaning rather than only for presentation. This improves accessibility, search engine optimization, and code readability by making the structure of the document more understandable to both browsers and developers.
